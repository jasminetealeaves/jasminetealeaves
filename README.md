# Yudi Hu

MS Computer Science student at Georgia Tech and former neuroscience researcher at UC San Diego. I work on signals and the pipelines around them, mostly in Python and SQL, and I like knowing what the data can and can't show.

### Projects
- **[eeg-confusion-anatomy](https://github.com/jasminetealeaves/eeg-confusion-anatomy)**: which brain states do EEG classifiers confuse, and is that the signal or the features? 500 recordings, 5 clinical conditions, 3 model families.
- **[movie-quality-scorer](https://github.com/jasminetealeaves/movie-quality-scorer)**: scores films for catalog triage from OMDb data with an LLM fallback, plus a write-up of a silent bug that scored unrated films as zero.
- **[newsletter-generator](https://github.com/jasminetealeaves/newsletter-generator)**: turns content IDs into send-ready HTML email. A sanitized rebuild of a tool an editorial team used every day for three years.
